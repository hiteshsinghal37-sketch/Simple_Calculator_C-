# Simple Calculator in C

## About the Project
This is a menu-driven calculator developed in C as part of the Programming in C (PPS) mini-project. It allows users to perform basic arithmetic operations and other mathematical calculations through a simple menu.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Factorial of a number
- Power calculation
- Percentage calculation
- Menu-driven interface
- Input validation for division by zero and negative factorial values

## Technologies Used
- **Programming Language:** C
- **Compiler:** MinGw
- **Editor:** Visual Studio Code

## Learning Outcomes
- Understanding conditional statements and loops
- Using functions in C
- Performing arithmetic operations
- Handling user input
- Implementing a menu-driven program
